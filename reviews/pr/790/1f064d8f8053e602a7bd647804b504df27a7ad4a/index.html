Acceptance criteria

  • [ ] One versioned machine-readable target/connection model separates mutable SSH coordinates/trust from Runtime identity.
  • [ ] Unknown/changed host key requires explicit trust action and cannot be silently accepted on reconnect.
  • [ ] Same Runtime can be deliberately rebound to changed transport coordinates only with independent Runtime/trust verification.
  • [ ] Reused hostname/IP pointing at an unrelated host fails rather than inheriting stored Runtime identity.
  • [ ] SSH process invocation is argv-safe, finite, bounded, and has stable error classification.
  • [ ] Persisted connection state contains no raw private key/token/agent secret and bounded status omits sensitive transport material.
  • [ ] Restart/reload preserves trusted target records and detects corrupted/ambiguous state fail-closed.
  • [ ] Tests cover first trust, repeat connection, host-key change, address change with same Runtime, address reuse by foreign Runtime, timeout/auth failure, and malformed state.
