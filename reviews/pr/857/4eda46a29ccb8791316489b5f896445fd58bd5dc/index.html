  • [ ] Historical release documentation is separated from current release operations.

  • [ ] All Japanese prose under `docs/**` is translated to English without changing normative semantics.
  • [ ] Repository documentation/governance documents an English-only/default-English policy.

  • [ ] No broken documentation links remain.
  • [ ] A mechanical check rejects new unclassified files directly under `docs/`, with `docs/README.md` as the intended exception.
  • [ ] The mechanical rule is integrated into the existing governance/CI standards path rather than creating an unrelated duplicate authority.
  • [ ] Documentation placement/language rules are discoverable from `docs/README.md` and repository governance documentation.
