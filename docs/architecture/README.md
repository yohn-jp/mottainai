# Architecture

Architecture documents describe stable system structure, ownership boundaries,
component relationships, and provider topology. They are current architectural
guidance unless a document explicitly records a historical decision.

Place structure and responsibility descriptions here. Do not place command
sequences, bounded compatibility contracts, test results, or operational
runbooks here; use `contracts/`, `testing/`, `reports/`, or `operations/`.
