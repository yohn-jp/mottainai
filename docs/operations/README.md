# Operations

Operations documents contain chronological procedures, golden paths, runbooks,
deployment and release flows, and instructions for operating or converging the
system. They are operational guidance, not the authority for the contracts
they exercise.

Place step-by-step procedures here. Do not place stable architecture,
normative schemas, point-in-time reports, or release history here; link to the
relevant authority instead.
