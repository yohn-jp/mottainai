# Reports

Reports preserve point-in-time observations and evidence: dogfood results,
experiments, and benchmark measurements. They are evidentiary and are not
current system authority unless explicitly promoted into `architecture/`,
`contracts/`, or `operations/`.

Place dated observations and reproducible measurement output here. Do not
place current requirements, procedures, or design-time artifacts here.
