# Mottainai 0.9.1

Mottainai 0.9.1 is a runtime-provisioning and CI-convergence patch release. It
fixes canonical Runtime Appliance boot and activated-path persistence, restores
managed PR state migration, and converges the repository's CI toolchain and
dependency posture onto shared, org-owned workflows.

## Runtime fixes

The canonical Runtime Appliance image is now UEFI/GPT bootable under Lima
(#817). Activated QEMU paths are persisted so they survive across restarts
instead of being recomputed inconsistently (#813, #814).

## Workflow fixes

Managed PR state migration, which had regressed, is restored (#800).

## CI and distribution

The repository now audits and converges its CI dependencies (#812), replaces
the local pnpm setup with the shared pnpm action (#810), migrates CodeQL
scanning to the shared org workflow (#809), pins the local Node toolchain to
24 via mise (#805), follows org-owned reusable workflows from `@main` (#803),
and fixes the packed bin smoke test (#801).

## Distribution

npm publishes the CLI and MCP package as `mottainai@0.9.1`.

## Upgrade

Use `mottainai@0.9.1` for the npm surface. No breaking changes to existing
configuration or state schemas are introduced by this release.
