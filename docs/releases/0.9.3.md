# Mottainai 0.9.3

Mottainai 0.9.3 is a release-infrastructure patch release. It fixes the ORAS
CLI flag mismatch that blocked the 0.9.2 Runtime Appliance OCI publish, the
release immediately after 0.9.1's own ORAS setup failure.

## Release infrastructure fixes

The 0.9.2 publish failed in the "Publish and round-trip verify the Runtime
Appliance OCI Artifact" step: `oras manifest fetch` and `oras tag` were
called with `--no-tty`, a flag that only exists on ORAS CLI's `push` and
`pull` subcommands and never existed on `manifest fetch` or `tag`. The 0.9.1
attempt never reached this code because its ORAS setup failed first (#821);
once that was fixed, 0.9.2 got past setup and the actual push, then failed
on the first `manifest fetch` call. `--no-tty` is removed from the affected
call sites, and a regression check now downloads the pinned ORAS CLI release
and verifies every `oras <subcommand> --flag` invocation in the release
workflow against that subcommand's real supported flags, before a release
reaches this step again (#834, #835).

## Distribution

npm publishes the CLI and MCP package as `mottainai@0.9.3`. This release
also completes the Runtime Appliance OCI Artifact publish that 0.9.1 and
0.9.2 could not reach.

## Upgrade

Use `mottainai@0.9.3` for the npm surface. No breaking changes to existing
configuration or state schemas are introduced by this release.
