# Contracts

Contracts are normative authorities for bounded interfaces, schemas, identity,
state, policy, compatibility, and externally or independently consumed
behavior. Implementations and integrations must satisfy the applicable
contract.

Place invariant and compatibility definitions here. Do not place explanatory
system structure, chronological procedures, test evidence, or historical
material here; use `architecture/`, `operations/`, `testing/`, `reports/`, or
`history/`.
