# Mottainai 0.8.3

Mottainai 0.8.3 is a patch release that executes the corrected draft-first publication lifecycle so the complete published deployment chain is externally consumable.

## Distribution

The release workflow now creates and retains a mutable draft GitHub Release while release assets are produced, uploads the standalone Linux x86_64 `mottainai-init` artifact and immutable deployment descriptor before publication, and finalizes the GitHub Release only after all required publication jobs succeed. This avoids the prior HTTP 422 failure caused by attempting to add assets to an already-published immutable release.

The npm Route 1 payload and canonical Runtime Appliance remain published through their existing npm and GHCR distribution surfaces. The GitHub Release assets provide the missing external entry point required by the Route 4 -> 3 -> 2 -> 1 real-host certification.

## Certification

After publication, v0.8.3 is the intended release identity for #261. Certification must start from the published standalone artifact and descriptor rather than locally built substitutes.

## Upgrade

Use `mottainai@0.8.3` for the npm surface. No intentional product behavior change is introduced by this patch release beyond completing the release distribution contract.
