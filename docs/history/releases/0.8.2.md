# Mottainai 0.8.2

Mottainai 0.8.2 is a patch release that fixes a CI-only defect in the Runtime Appliance GHCR publication workflow (#733), unblocking #709.

## Runtime distribution

v0.8.1's release run pushed the canonical Runtime Appliance to GHCR successfully, but the workflow's own round-trip verification step then failed with an unbound shell variable (`compressed_sha256`), introduced by #685's added metadata cross-check and never exercised on a pull request because that step only runs on a published release. The job reported failure even though the artifact itself was published correctly. `publish.yml` now derives `compressed_sha256` alongside the existing `compressed_digest` so the verification step runs to completion (#733).

## Distribution

npm publishes the CLI and MCP package as `mottainai@0.8.2`. The canonical Runtime Appliance for this release is published to GHCR at the exact `v0.8.2` source revision; its immutable manifest digest is the value required by `RuntimeSpec.appliance` and `mottainai-init runtime ensure --spec ...`.

## Upgrade

Use `mottainai@0.8.2` for the npm surface. No behavioral changes beyond the CI fix.
