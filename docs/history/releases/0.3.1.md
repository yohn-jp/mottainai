# Mottainai 0.3.1

Mottainai 0.3.1 is a focused patch release correcting the Dashboard runtime UI shipped in 0.3.0.

## Fixed

`mottainai dashboard` no longer serves the legacy dark `semantic-project-viewer-v2.html`. The Dashboard now uses the current light, dense Mottainai precision UX through an API-backed Semantic Project Viewer v3.

The replacement preserves the existing semantic surfaces:

- Overview
- Components
- Dependencies
- Change Impact
- Knowledge
- entity inspection with summary, static facts, relations, history, and agent projection

## Authority and compatibility

This is a presentation/runtime-asset correction, not a semantic authority migration. Dashboard data continues to come from the existing read-only `/api/v1/*` RepositorySemanticQuery endpoints. Fixture/live provider selection, loopback-only serving, `--no-open`, explicit port handling, and public query schemas are unchanged.

The Dashboard does not adopt Wabachi as a data authority and does not embed a replacement semantic fixture dataset in the UI.

## Distribution

The build now packages `semantic-project-viewer-v3.html` and the shared current `styles.css` as the Dashboard runtime assets. Regression coverage verifies the root viewer and stylesheet wiring and rejects accidental fallback to the v2 runtime asset.

## Upgrade

After publication, use `mottainai@0.3.1`. Users of 0.3.0 who use `mottainai dashboard` should upgrade; managed workflow and Manager behavior are otherwise unchanged.
