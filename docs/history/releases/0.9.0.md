# Mottainai 0.9.0

Mottainai 0.9.0 is a workflow-identity and runtime-identity release. It adds durable identity primitives across the workflow, runtime, and security surfaces — Makami PR lifecycle state, Canon prefix/attachment identity, Runtime-scoped Manager identity, verified SSH target identity, and durable repository Unix principals — and hardens config durability and the release publication pipeline.

## Workflow identity

Makami PR lifecycle generation is now persisted through a dedicated workflow domain and SQLite-backed store (#792), and governed task artifacts resolve through gh-inari instead of ad hoc lookups (#411, #794). Canon gains deterministic prefix and attachment identities, giving Canon-owned artifacts a stable, reproducible identity (#409, #789).

## Runtime and security identity

Manager gains Runtime-scoped identity, carried through the HTTP boundary and persisted alongside existing session state (#421, #793). Verified SSH target identity is persisted for the runtime contract (#298, #790). Durable repository Unix principals are allocated so repository-scoped execution has a stable identity to run under (#791).

## Fixes

Post-rename config durability failures are now distinguished from other atomic-write failures instead of being reported generically (#673, #786). The release workflow's draft-release tag resolution and finalize-release gating are hardened against the failure modes uncovered while shipping 0.8.3 (#726, #795).

## CI

The repository now consumes the shared TypeScript CI foundation (#301, #788) and the shared CodeQL workflow (#440, #784) instead of maintaining repository-local equivalents. The local npm publish exception is documented (#303, #787).

## Distribution

npm publishes the CLI and MCP package as `mottainai@0.9.0`.

## Upgrade

Use `mottainai@0.9.0` for the npm surface. No breaking changes to existing configuration or state schemas are introduced by this release.
